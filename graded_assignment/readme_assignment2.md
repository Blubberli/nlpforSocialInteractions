### LLM as an Annotator

- models provided: Llama 3, Qwen 
- Prompt Design: Craft clear and specific prompts to guide the LLM. Test different prompts to make sure that the output format you get looks the way you want it to look (you can extract clear labels from it)
- python scripts:
  - packages required
    - pandas, openai
  - /tmp/data_nlpforsocialinteractions/test_prompt_vllm.py
    - this script can be used to test different prompts on an examples instance
    - usage: usage: test_prompt_vllm.py [-h] [--system SYSTEM] --user USER [--input INPUT] [--model MODEL] [--temp TEMP]
      - SYSTEM: system prompt, does not need to be specified, there is a default
      - USER: user prompt, needs to be specified, for example "Does the text express an concern/belief/attitude/emotion about Egalitarian treatment and equal outcomes for all individuals and groups? Answer with yes or no." For a longer prompt you should use a .txt file instead.
      - INPUT: input text, an example you want to test or an example datapoint from the dataset. This can also be a string in the terminal or a .txt file.
      - MODEL: model to use, default is Meta-Llama-3-8B-Instruct
      - TEMP: temperature for the model, default is 0.6 (lower temperature means more deterministic output, higher temperature means more random ('creative') output)
    - example usage:
      - python test_prompt_vllm.py --user "Does the text express an concern/belief/attitude/emotion about Egalitarian treatment and equal outcomes for all individuals and groups? Answer with yes or no." --input "Everyone should have the same opportunities regardless of their background."
  - /tmp/data_nlpforsocialinteractions/run_prompt_dataset.py
    - this script can be used to annotate a whole dataset with an llm
    - usage: run_prompt_dataset.py [-h] --input_file INPUT_FILE --output_file OUTPUT_FILE --text_column TEXT_COLUMN --user_prompt USER_PROMPT [--system_prompt SYSTEM_PROMPT] [--use_json] [--model MODEL] [--temperature TEMPERATURE] [--sep SEP]
      - SYSTEM, USER, MODEL, TEMP: as above.
      - OUTPUT_FILE: path to the output csv file where the annotations will be saved
      - TEXT_COLUMN: name of the column in the input csv file that contains the text to be annotated. represents the input to the llm.
      - sep: separator for the csv file, default is comma (,)
      - use_json: if specified, the output will be saved in json format instead of csv. If you want this you should make the expected structure explicit in the prompt. This can be useful for further processing.
    - example usage:
      - python annotate_with_llm.py --user "Does the text express an concern/belief/attitude/emotion about Egalitarian treatment and equal outcomes for all individuals and groups? Answer with yes or no." --input_file ./data/moral_foundations/reddit_moral_foundations.csv --output_file ./data/moral_foundations/reddit_moral_foundations_annotated.csv
