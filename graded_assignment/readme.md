### Requirements / Notes on the Grading

- You need to submit a PDF file of your report. Minimum 4 pages, maximum 8 pages 
- You do not need to add literature references, but you can if you want to
- language: the quality of the writing will *not* be graded (just make sure it is understandable)
- code: I will *not* grade the quality of your code. I want you to submit your code in a GitHub repository, in case I want to check if it is compatible with your report and not completely generated by genAI. The code can be messy and undocumented (of course I recommend to document it nevertheless :))
- genAI: you can *not* use generative AI tools to generate new text. You can use genAI to check for spelling or grammar but you need to mention it in the report. You should also not use genAI to generate code from scratch but you can use it for debugging (or if you have co-pilot for autocompletion). Also this type of use needs to be made transparent (Appendix of the report)
- plagiarism: you need to submit your own work. You can discuss with others but the report needs to be written by yourself.
- extension: if you need an extension for any reason, please contact me at least 2 days before the deadline.
