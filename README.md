# Practical Part  for NLP for Social Interactions

This repository contains the notebooks, assignments and information for the practical session for NLP for social Identity.
The goal of the practical sessions is to learn how to empirically analyze social interactions using NLP techniques. 
It should provide some idea of useful tools to represent and process conversational data, how these data look like and what type of annotations they have.

## Structure of the repository
The repository is structured as follows:
- `notebooks/`: This folder contains Jupyter notebooks that guide you through various NLP techniques and their application to social interaction data.

The notebooks contain explanations, code examples, and exercises to help you understand the concepts and apply them.
Every notebook also will come with a solution notebook that contains the solutions to the exercises.
